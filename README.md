# APEX Enjoy Tool

APEX Legendsをもっと楽しむためのツール集。

## 機能

### レジェンドピッカー
- ルーレット演出付きのランダムレジェンド抽選
- 人数変更対応（ソロ / デュオ / トリオ）— 重複なしで一括抽選
- レジェンドごとに「通常 / ★お気に入り（3倍出やすい） / 除外」を設定可能

### 武器セレクター
- 武器2枠セットのランダム抽選
- バランス重視モード（近距離枠 + 中遠距離枠から1本ずつ）
- ケアパッケージ武器の含む/含まない切り替え
- 武器ごとに「通常 / ★お気に入り / 除外」を設定可能

設定はすべてlocalStorageに自動保存されます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 型チェック + 本番ビルド（dist/）
```

## データの更新

シーズン更新でレジェンド・武器が変わったら以下を編集：

- `src/data/legends.ts` — レジェンド一覧（S29 SP2時点・全28キャラ）
- `src/data/weapons.ts` — 武器一覧・ケアパッケージ武器の`carePackage`フラグ
